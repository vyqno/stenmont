# How we used AI

ETHGlobal asks every team to say plainly how AI was used. This is the honest version for Stenmont.

## What AI did

- **Most of the code was written by AI coding agents working from our written plans.** We used Claude Code (Claude Opus and Sonnet models) and OpenAI Codex. They wrote the Solidity contracts and their tests, the API (Cloudflare Workers), the dashboard and pay page, the SDK and React button, the MCP and x402 services, and the Shopify bridge.
- **Review by a second model.** A second model reviewed the first one's work; the findings and the fixes are in `plan/review-opus-1.md` and the git history.
- **Security tooling.** We ran Pashov's `solidity-auditor` and `x-ray` skills and Slither against the contracts, and fixed what they found.
- **Browser agent.** An AI browser (Aside) helped configure the World and Shopify developer portals and fill the hackathon forms.
- **Imagery.** Codex generated the brand card images. The dithered mountain on the landing page is generated by a script in the repository history, not by an image model.

## What humans did

- Chose the product, the architecture, the brand and every trade-off.
- Wrote the plans, reviewed the output, deployed, and ran the real tests on real devices: passkeys, World App, wallets, the Shopify store.
- Decided what to cut, what to label as "not live", and what to claim.

## Limits of what we can claim

AI wrote code quickly, but speed is not proof. The contracts have **no external audit**. What we call "proven live" means we ran it on the test network and kept the transaction. Everything else is labelled "built" or "not run" in [docs/TRACK-CHECKLIST.md](docs/TRACK-CHECKLIST.md).
