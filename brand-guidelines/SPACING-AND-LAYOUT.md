# Spacing and layout

## Base system

Use a 4 px unit. Spacing tokens: 4, 8, 12, 16, 24, 32, 48, 64, 96. Related labels and values use 4–8; control groups 12–16; sections 32–48; editorial sections 64–96. Avoid arbitrary near-duplicates.

| Width | Grid | Outer gutter | Column gap |
|---|---|---|---|
| Below 640 px | 4 columns | 16 px | 16 px |
| 640–1023 px | 8 columns | 24 px | 24 px |
| 1024 px and above | 12 columns | 32 px | 24 px |

Container max: 1200 px marketing, 1440 px dashboard workspace, 1120 px documentation, 720 px reading column, 560 px checkout. These are new-brand specifications; app adoption is deferred. Breakpoints express available space, not device identification.

## Alignment and density

Align titles, rules, content and footers to the same left edge. Use tabular right-aligned amounts and left-aligned descriptions. Reserve stable row height for statuses. Do not center dense operational information. Keep captions attached to their evidence.

On small screens stack panels in task order, wrap identifiers, retain readable labels and expose table scrolling with a clear cue. Keep navigation keyboard reachable. For print use a 12-column page grid with 16 mm margins and avoid splitting a transaction row across pages.
