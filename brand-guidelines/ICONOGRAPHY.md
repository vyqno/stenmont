# Iconography

No shared icon-library dependency was found in the web package manifest during this audit. Existing framework starter SVGs are not Stenmont icons. Do not add a library for this documentation task.

## Construction

Use a 24 × 24 viewBox, a 2 px safe inset, 1.5 px stroke, round caps and joins, and no fill. Align vertical/horizontal edges optically at native size; do not mix this set with filled or multicolour icons. Standard sizes: 16, 20 and 24 px, retaining the same apparent weight. Large illustrations use their own 2 px stroke.

`assets/icons/functional.svg` is an original documentation sprite for record, checkout, webhook, identity, security and agent approval. It is a proposed functional set, not a logo. Each symbol has a stable id. Review ambiguous forms with users before adoption.

## States and access

Inactive uses Ink, selected may use Ink on Cornflower, disabled uses Ink at 40% with an explicit disabled control state. Never communicate approval solely through an icon or a coloured dot. Pair important status with words. Decorative icons are hidden from assistive technology; icon-only controls need an accessible name and a 44 px target. A security icon is not evidence of an audit or certification.
