# Stenmont brand guidelines

This manual records the founder-approved identity direction. It is documentation and editable SVG only; the current app still uses legacy Whitechain tokens.

Start with [BRAND-BOOK.md](BRAND-BOOK.md). Detailed rules live in BRAND-STRATEGY, LOGO, TYPOGRAPHY, COLORS, VISUAL-LANGUAGE, ICONOGRAPHY, VOICE-AND-TONE, MESSAGING, SPACING-AND-LAYOUT, ACCESSIBILITY, UI-DESIGN-SYSTEM, MOTION and BRAND-APPLICATIONS.
